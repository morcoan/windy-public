# Changelog

## 0.3.1 — Bounded capability hotfix

- Kept capability discovery on the compact catalog path instead of promoting
  large PE targets into the full instruction-decoding pipeline.
- Added executable, paginated `list_imports` action tickets backed by cached PE
  catalog data.
- Added an MCP regression proving catalog capability execution does not create
  a full `Project`.

## 0.3.0 — Evidence Query VM

- Replaced the v0.2 surface with six agent-only MCP tools and opaque,
  action-id-only continuations.
- Added demand-driven mapped, catalog, sketch, function, global, and explicit
  deep stages with checksummed structural cache partitions.
- Added compact function sketches, constraint-intersection retrieval, and
  graph-backed verification without retaining decoded instructions globally.
- Added an eight-byte partitioned deep instruction index and stopped automatic
  whole-image BEL construction.
- Added the deterministic SQLite microbenchmark and failure-driven Luna
  evaluation loop; models and training remain external to Windy.
- Added durable rename/comment proposals with revision, idempotency, close,
  reopen, and persistence verification continuations.
- Removed obsolete GUI, beta-packaging, model-training, and historical
  release-candidate artifacts from the public tree.

## 0.2.0 — Agent-first MCP architecture

- Removed the GUI, window/GPU dependency graph, startup target arguments, and
  automatic recent-project reopen.
- Made `windy` a loopback MCP host with a read-only terminal statistics display.
- Replaced the wide API with twelve MCP v2 tools plus deterministic capability
  discovery, response envelopes, artifact paging, and safe edits.
- Removed the product-facing agent binary and moved model experiments into
  external evaluation clients.

## Earlier releases

Windy v0.1 established the native PE analysis, decompiler, evidence, dump, and
workspace foundations. Detailed historical notes and benchmark snapshots remain
available through Git tags and repository history.
