## Evidence-first investigation

Windy opened 18,232 functions covering 1,282,746 instructions. Triage used exports, imports, strings, sections, indexed search, and then bounded function evidence. The investigation inspected at least these functions:

| Function | VA | Evidence-backed role |
|---|---:|---|
| `CreateInterface` | `0x180408cd0` | Walks a linked list of interface registrations, compares the requested name, returns status 1/null when absent, or status 0 and tail-calls the matching factory. |
| `Source2Main` | `0x180216db0` | Performs process/thread and crash-reporting startup scaffolding, calls the lifecycle delegate at `0x180213cb0`, then runs Steam/platform cleanup. |
| `FUN_180213cb0` | `0x180213cb0` | Large startup/lifecycle delegate called by `Source2Main`; exact subsystem ordering remains unresolved. |
| `FUN_180406360` | `0x180406360` | Small helper reached during startup; inspected to avoid inferring the full lifecycle from the export alone. |

`CreateInterface` evidence identifies the registration-node layout used by the lookup: factory pointer at `+0`, name at `+8`, next at `+0x10`, with the list head read from `0x180691b98`. This supports the factory-registry behavior; it does not enumerate the live list without runtime state.

`Source2Main` evidence resolves calls including `KeyValuesSystem`, `DeclareCurrentThreadIsMainThread`, `CommandLine`, `Tier0GenericMiniDumpHandler_SetOptions`, `Plat_AttachDebuggerToProcess`, minidump/logging handlers, `SteamAPI_Shutdown`, and `Plat_OnExecutableExitingMain`. Its direct call at `0x180216f7f` transfers control to `0x180213cb0`; cleanup follows that call.

## Dogfood findings and disposition

| Severity | Finding | Disposition |
|---|---|---|
| P0 | RIP-relative call targets were double-based even though iced-x86 already supplied an absolute address, producing materially false call evidence. | Fixed by using the decoder's IP-relative address directly. Regression test: `rip_relative_target_is_not_double_based`. |
| P1 | Imported API claims could contradict visible IAT call sites. | Fixed by resolving RIP-relative indirect-call IAT slots in API evidence. Regression test: `imported_api_recovers_rip_relative_iat_call`; the eight final claims are supported. |
| P1 | `search_summary("CreateInterface")` timed out after 120 seconds on the target. | Fixed with indexed symbol/string fast paths. Regression test: `search_summary_prefers_indexed_import_symbol_hits`; final packaged search completed in 18.63 ms. |
| P2 | Standalone Codex CLI discovery/execution was unavailable in the desktop environment. | Recorded for post-v0.1 client/setup documentation; direct Codex MCP use succeeded within the timing limit. |
| P2 | Local PowerShell execution policy blocked direct `.ps1` invocation. | Used a process-scoped `-ExecutionPolicy Bypass`; no machine policy was changed. Recorded as setup friction. |
| Diagnostic | The target had no CodeView/PDB record. | Expected and non-blocking; uncertainty is retained above. |

No unresolved P0 or P1 remains. No speculative feature or decompiler redesign was added.
